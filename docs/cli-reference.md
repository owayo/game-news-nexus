# コマンドライン

| オプション | 説明 |
| --- | --- |
| `--hidden` | ウィンドウを出さずにトレイ (macOS はメニューバー) で起動する (自動起動向け) |
| `--fetch-once` | 画面を出さずに、カタログを取り込んでから on のソースを 1 度ずつ取得し、予定も読み取って終わる。結果を標準出力に出し、失敗があれば終了コード 1 |
| `--quit` | 起動中のアプリに終了を頼み (トレイの「終了」と同じく、取得を止め、データベースへの書き込みを済ませてから終わる)、終わるまで最大 30 秒待つ。起動していなければ何もしない (データのディレクトリも作らない)。終了コードは 0 (終わった・起動していなかった)、1 (伝えられない・時間内に終わらない・別の実行ファイルで起動している) |
| `-h`, `--help` | 説明を出す |

`--fetch-once` は常駐中も使えます。購読の保存などと重なってロックを取れなかった場合は、購読を変更せずに エラーで終了します。少し待ってから実行し直してください。

`--hidden`・`--fetch-once`・`--quit` は一緒に使えません (終了コード 2)。

すでに起動しているときにもう一度起動すると、起動中のウィンドウを前に出して終わります (`--hidden` を付けたときは、ウィンドウを出させずに終わります)。macOS で Dock・Finder・Launchpad から開いたときは 2 つ目は起動せず、起動中のアプリがウィンドウを出します。

`--quit` は、同じ設定とデータの場所 (`GNN_HOME`) を使い、同じ実行ファイルで起動しているアプリだけを終了させます (別の場所の実行ファイルで起動しているときは、終了させずに 1 で終わります)。macOS では、端末から `.app` の中の実行ファイルを直接起動します (`"/Applications/Game News Nexus.app/Contents/MacOS/game-news-nexus" --quit`)。 `open` や Dock・Finder からでは 2 つ目が起動しないので届かず、起動中のアプリを前に出すだけです。メニューの 「終了」(`⌘Q`) やメニューバーのアイコンの「終了」でも、同じ後始末をして終わります。
